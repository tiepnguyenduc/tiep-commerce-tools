Use the installed commercetools plugin and follow its commercetools-storefront and commercetools-checkout skills.

Create a runnable training storefront in this folder from scratch.

Hard constraints:

- Do not commit.
- Do not push.
- Do not write outside this project folder.
- Use Next.js 16 App Router with TypeScript.
- Use the BFF pattern: all commercetools calls go through server code/API route handlers.
- Never expose CTP_CLIENT_SECRET or server-only commercetools credentials to the browser.
- Keep commercetools SDK imports inside server-only modules under lib/ct/*.
- Use app-level mapped types for frontend components.
- Include .env.example and README.md.
- The app must run locally with npm install and npm run dev.
- If real commercetools env is missing, app must still run with deterministic mock/sample data for training.

Required storefront scope:

- B2C and B2B landing/home paths.
- Product listing page with search/facet UI.
- Product detail page.
- Cart with add/remove/update quantity.
- B2C checkout flow.
- B2B checkout flow with business unit, purchase order, and approval-pending training path.
- commercetools Checkout Browser SDK integration path: create checkout session through BFF, initialize checkoutFlow or paymentFlow from browser when env is configured, otherwise show local training fallback.
- Customer/account training page.
- Docs that explain how this maps to:
  - commercetools initial setup
  - Product Search API
  - B2C cart/order
  - B2B as-associate pattern
  - Checkout Browser SDK
  - Frontend Studio vs AI plugin distinction

Use dependencies appropriate for the official plugin guidance:

- next@^16
- react/react-dom
- zod
- @commercetools/platform-sdk
- @commercetools/sdk-client-v2 or current required SDK package if needed by platform-sdk
- @commercetools/checkout-browser-sdk
- vitest for tests

Visual direction:

- Make the UI closer to a polished commerce launchpad than a minimal demo:
  - strong hero section
  - category cards
  - product cards with images
  - clear B2C/B2B mode selector
  - cart and checkout pages that visibly demonstrate the goal

Verification:

- Add basic tests for env readiness and local cart/checkout behavior.
- Run npm install if needed.
- Run npm run typecheck, npm test, and npm run build.
- If a command cannot run, report the exact blocker in README and final response.
